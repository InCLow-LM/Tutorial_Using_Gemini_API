## Tutorial for using Gemini Models with API on Google Cloud

This is the repository to guide the usage of Gemini APIs on Google Cloud.

- For the professor/supervisor, you could check the [Tutorial_Using_Gemini_API_[Teacher]](https://github.com/InCLow-LM/Tutorial_Using_Gemini_API/blob/main/Tutorial_Using_Gemini_API_%5BTeacher%5D.ipynb) to see how to config or grant X to help with the configuration.
- For the students, you could find two ways (Standard inference & **half-priced** batch inference) to use the Gemini models with API in [Tutorial_Using_Gemini_API_[Student].ipynb](https://github.com/InCLow-LM/Tutorial_Using_Gemini_API/blob/main/Tutorial_Using_Gemini_API_%5BStudent%5D.ipynb).
