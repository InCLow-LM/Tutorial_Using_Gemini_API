## Tutorial for using Gemini Models with API on Google Cloud

This is the repository to guide the usage of Gemini APIs on Google Cloud.

- [Tutorial_Using_Gemini_API [Admin]](https://github.com/InCLow-LM/Tutorial_Using_Gemini_API/blob/main/Tutorial_Using_Gemini_API%20%5BAdmin%5D.ipynb): For the **supervisor (or authorized administrators)**, you could find how to (i) config by yourself, or (ii) grant someone else (X) to help with the configuration alternatively.
- [Tutorial_Using_Gemini_API [Users].ipynb](https://github.com/InCLow-LM/Tutorial_Using_Gemini_API/blob/main/Tutorial_Using_Gemini_API%20%5BUsers%5D.ipynb): For the **students (or credit users)**, you could find two ways (Standard inference & **half-priced** batch inference) to use the Gemini models with API.
